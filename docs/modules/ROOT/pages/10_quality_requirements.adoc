== 10.2 Quality Scenarios

[cols="1,3,4",options="header"]
|===
|# |Scenario |Expected behavior

|Q1
|User has no `ANTHROPIC_API_KEY`
|All non-AI features fully functional; AI buttons hidden; AI endpoints return 503 with a helpful message

|Q2
|API key is invalid/revoked
|Friendly error ("key was rejected — check server/.env"), no crash, no stack trace in the UI

|Q3
|User selects a semester of lecture PDFs
|Estimate shows token count + cost first; requests over 180K input tokens rejected with "deselect some materials"

|Q4
|Same materials, second AI call within 5 min
|Prompt cache hit — `cache_read_input_tokens > 0`, ~10% of first-call input cost

|Q5
|Timer running, browser closed and reopened
|TimerBar restores from server state; elapsed time correct

|Q6
|Two timers started in sequence
|First entry auto-closed in the same transaction; never two running entries

|Q7
|Parent task completed while subtasks open
|409 with "complete all subtasks first"

|Q8
|Task reopened after completion
|Latest completion row removed — XP cannot be farmed

|Q9
|Draw with only oversized tasks left
|`all_too_big` reason → UI links to breakdown, not a dead end

|Q10
|40 draws over a mixed deck
|High-impact/low-effort tasks visibly dominate; due-today tasks outdraw higher-impact undated ones; 1★ slogs are rare

|Q11
|Server killed mid-write
|SQLite WAL keeps the database consistent

|Q12
|Fresh checkout on a new Windows machine
|`npm install && npm run dev` works without a compiler toolchain (prebuilt binaries)

|Q13
|Reload while the focus countdown runs on the drawn card
|Focus view restores from persisted draw + timer (ADR-29); a timer stopped meanwhile degrades to the plain revealed card — never a dead overlay

|Q14
|A pack POST loses its response or the tab reloads with an unresolved purchase
|One tab-scoped payment-bound ref blocks new purchases; only the initial transport failure retries once, reload waits for explicit same-ref resume, and a definitive replay/error clears the intent without optimistic economy changes

|Q15
|A keyboard or screen-reader user opens a pack, or the user requests reduced motion
|One named modal exposes the returned background before its optional effective bonus, keeps hidden facts out of accessibility output, traps/restores focus, and offers explicit Reveal/Skip/Close/Escape; reduced motion opens the identical complete facts with no reveal motion or confetti

|Q16
|Draw restarts, overlaps a repeated wall hour, or sees a provider/DNS failure after claiming today's digest
|The enrolled device/local date has one retained claim and Draw initiates at most one provider request; no application retry or next-day backlog is created

|Q17
|A digest window crosses DST, quiet hours, or local midnight, or Hide-details is enabled
|Saved-IANA-zone evaluation uses the approved gap/fold and half-open rules; TTL is only the positive whole-second lifetime remaining up to three hours and never crosses local midnight; Hide-details constructs counts only

|Q18
|The same valid fixed local minute and entry zone reach two supported hosts, including a fall fold
|The checked-in tzdb-2026b canonical-zone policy resolves the same instant; a fold chooses the earlier instant, a gap or UTC year outside `0001`–`9999` rejects without mutation

|Q19
|A current or candidate task gains a fixed slot
|It immediately leaves Draw, current and warm-up state clear atomically, and clear never auto-deals; client and server classification agree

|Q20
|A valid or tampered v22 fixed-slot database is restarted, exported or restored
|Valid slot/zone data survives; malformed relation/index/zone/instant/order/round-trip/recurrence state rejects before live swap

|Q21
|Ordinary production code or a crafted v1–v24 restore attempts native/path recovery, schema mutation, protected-name access, unknown executable/virtual schema, or oversized schema SQL
|The frozen facade rejects before native preparation and leaves bytes unchanged; bounded exact staged preflight rejects before integrity/migration/source access and never swaps live data

|Q22
|Schema v23 sees historical, boundary, open, malformed or drifting fixed/tracked interval source, or an owned mutation fails mid-transaction
|Lazy guards admit only canonical 24-byte TEXT timestamps; bounded keyset rebuild/validation retains no full-history JavaScript array; the numeric companion and RTree are complete for eligible source, dirty/rebuild is explicit, and source/companion/RTree/state roll back together without a history cutoff, numeric performance SLA or user-content projection

|Q23
|A Week request covers dense history, a DST/boundary Week, concurrent access, stale/tampered cursor, or a restore
|The ready-v23 RTree/index query returns one coherent ordered page of at most 100 records; all JavaScript/IPC/wire data are bounded, a second request is busy, cursor failure reaches no SQL, and restore proves worker closure and rotates the key only after commit

|Q24
|A selected source title is arbitrarily large or has a UTF-8 boundary/error
|Only the page-budget prefix plus four bytes enters JavaScript; intact records defer and lone oversized records truncate code-point-safely at or below 131,072 bytes. Invalid fetched bytes fail the page. SQLite-native title materialization, fatal native OOM/abort response availability, and process survival remain explicitly unbounded residual risk (issue #360)

|Q25
|A user opens, pages, navigates or acts in Week while responses are delayed, a cursor expires, or the viewport narrows
|Only the active strict-decoded generation renders; action results/refreshes are mount/Week/zone/token-bound, one continuation 400 resets once without mixing, every other failure is explicit, desktop lanes and narrow agenda preserve the same facts/order/actions, authoritative fixed editing retains its entry zone, and Week unmounts/releases inactive exact unpaged List task/goal data without disturbing another observer or performing an implicit write

|Q26
|Done, Stop, replacement Start, split, parent lifecycle, reopen, archive or destructive delete races to finish or remove a working session
|The guarded owner writes timestamp plus `done{vbar}stop` atomically and first close wins; non-closing paths leave it running, reopen preserves finished reason, parent exceptions retain their existing transaction, and task/subtree deletion erases its own sessions without classification

|Q27
|A forest request is malformed, paginates dense/sparse history, reaches zero duration or malformed classified data, or encounters a read failure
|Authentication remains first; the strict 2,048-byte bodyless raw-target grammar rejects without writes; the 101-row read emits at most 100 exact metadata-free trees with exclusive nullable exhaustion, validates the complete page, keeps no-store, and returns exact 400/500 contracts without partial success
|===

Q1, Q3 (guardrail), Q6–Q10, Q13–Q22 and Q26–Q27 are covered by the automated suites
(unit / integration / E2E — see xref:08_crosscutting_concepts.adoc[8.7]). For
Q23, `week-full-source-oracle.test.ts` scans the source tables with an
independent test algorithm (it does not import the production projection query
or ordering helpers) and compares the complete concatenated production pages
for DST/domain, sparse/dense, crosser, state, tie, deep-page and exact
99/100/101 fixtures. `week-production-worker.test.ts` loads test-only observer
and deterministic-fault modules from `test/instrumentation/` through the test
process options; those modules are outside the production import graph and add
no route, worker protocol field or production hook. The suite instruments the
real `WeekProjectionService` and `weekWorker.ts` connection/query/result path,
including lazy/reused sole connection, main-thread health during a blocked
query, HTTP disconnect/busy behavior, prefix-query/IPC bounds, recoverable
failure envelopes, and actual-worker protocol/structural fault retirement with
owned exit before restore, lazy recreation and shutdown. Static native/import
canaries are supplementary and are not treated as runtime proof. Existing WAL
and restore suites cover coherent old/new/dirty snapshots and reopen/key order.

Q24 is covered by reservation-aware 131,071/131,072/131,073 candidate-envelope
fixtures: each uses the conservative 375-character continuation reservation,
then distinguishes it from the real authenticated cursor and final wire body.
They also prove intact deferral, actual continuation, code-point-safe
truncation, escaping/control/combining/prefix boundaries and unchanged source
bytes. Non-thresholded native characterization records observations only. Q25
is covered by pure zone/calendar/lane/page tests and deterministic browser
fixtures for durable navigation, desktop/mobile/keyboard presentation, hostile
text, strict invalid-page rejection, paging, stale aborts, once-only cursor
reset, exact error states and the complete action matrix. A separate public
server-clock journey starts and stops a real timer and checks bounded timestamps
and unchanged planning facts. The Phase 2A/2B regression gate additionally runs
server/client types, all unit and
integration tests, documentation assembly, and the complete browser suite;
this does not convert fakes, static checks or characterization into runtime
claims. Q2 and Q4 need a live API key and are verified manually; Q5 is covered
by the E2E timer journey; Q11/Q12 are properties of SQLite WAL and prebuilt
binaries.
