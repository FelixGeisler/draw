[cols="1,3",options="header"]
|===
|Aspect |Detail

|Install
|`npm install` (workspace root)

|Run
|`npm run dev`; browser at `http://localhost:5173`

|Configuration
|`server/.env`: `ANTHROPIC_API_KEY` (optional), `API_PORT` (default 3001). `PORT` is deliberately not used — dev tooling injects it

|Data
|Everything under `server/data/` (gitignored); backup = copy that folder

|Docs hosting
|GitHub Pages serves the Antora-built site, deployed by the `Docs` Actions workflow on pushes to `main`
|===

*Outbound network:* only `api.anthropic.com`, and only when an AI feature is
explicitly invoked with a configured key.
